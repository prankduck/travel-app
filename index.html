設定旅行同步 Gist
填入這趟旅行的旅行代碼（Gist ID），不同旅行使用不同代碼，可控制誰能存取哪趟旅行的資料。
旅行代碼由旅行發起人使用 GitHub 設定小幫手建立，或自行在 GitHub 上建立 Gist 取得。
